## Tasks
The 3rd LLMs4OL Challenge consists of 3 tasks:

* **Task A - Flagship Task**: Given raw text, construct a primitive ontology including terms, types, taxonomy, and relations.
* **Task B - Reuse Task**: Given a partial ontology, add new concepts and relations extracted from text.
* **Task C - Taxonomy Task**: Given ontologies from source domains, induce a hierarchical taxonomy for an unseen domain.

The detailed instruction on how to access the Task C train dataset is provided at: [https://sites.google.com/view/llms4ol2026/taxonomy-task](https://sites.google.com/view/llms4ol2026/taxonomy-task).

## Challenge Phases
Two main phases for the challenge are:

1. **Solution Submission Phase** – Participants should develop and submit system outputs addressing one or more of the challenge tasks. Submissions will be evaluated using standardized metrics.
2. **System Integration Phase** – Participants integrate their systems with the [OntoLearner](https://ontolearner.readthedocs.io/) platform to enable reproducible benchmarking. This phase is open to both new participants and previous years’ participants who wish to contribute their system implementations to the platform. However, this is mandatory for participants of phase 1.
